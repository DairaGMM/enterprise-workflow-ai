## 🚀 Overview
**SynapseFlow** is an AI-powered enterprise productivity assistant built for the Frontier Cascadia Hackathon. It eliminates administrative overhead by parsing unstructured team communication and instantly extracting:
- **Executive Summary:** High-level bullet points for leadership and stakeholders.
- **Action Item Board:** Structured task cards with automatically assigned owners, priorities (High / Medium / Low), and deadlines.
- **Automated Follow-up Email:** Ready-to-send email drafts with one-click clipboard copying.

---

## 🛠️ Tech Stack & Architecture
- **Frontend:** HTML5, Modern Responsive CSS / Tailwind, Vanilla JavaScript
- **Deployment:** GitHub Pages (Zero-latency client-side execution)
- **AI Automation Logic:** Structured JSON schema extraction for predictable enterprise output
